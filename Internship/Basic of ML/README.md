# Basic of ML

## Overview
This directory covers the foundational Python programming language concepts practiced at the start of the internship. It establishes the basic coding skills necessary for data processing and machine learning workflows.

## Contents
- **`basic.ipynb`**: A Jupyter notebook containing code examples and exercises for fundamental Python concepts:
  - Variables and data types (strings, integers, floats)
  - Conditional statements (if-elif-else)
  - Iteration (for loops, while loops)
  - Custom functions and parameter passing
  - List and dictionary comprehensions
  - Exception handling (try-except blocks)
  - File reading and writing operations
  - Object-Oriented Programming (classes and objects)
- **`student_result.txt`**: A text file generated by the file handling exercise in the notebook, containing a mock student evaluation record:
  ```text
  Student Result
  Name: Ali
  Average: 85.25
  Grade: A
  ```

## Key Learning Outcomes
- Understanding basic syntax and data structures in Python.
- Writing modular, reusable code using functions.
- Performing basic file I/O operations to save script outputs.
