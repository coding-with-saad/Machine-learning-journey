# Day 1: Basic Python Tasks

## Overview
This directory contains a collection of Python scripts demonstrating fundamental syntax, control structures, and object-oriented programming concepts. It serves as a comprehensive refresher on Python fundamentals, structured as separate runnable exercises.

## Contents
- **`Variable and datatype.py`**: Declaring and manipulating basic types (integers, floats, strings, booleans).
- **`conditionalstatement.py`**: Implementing conditional logic (if-elif-else) for voting eligibility and other conditions.
- **`whileloop.py`**: Using loop conditions, including a mock login attempt program with password validation.
- **`forloops.py`**: Iterating over collections and number ranges.
- **`list.py`**: Declaring lists, modifying list elements, and using list operations.
- **`tuple.py`**: Exploring tuples, demonstrating immutability and indexing.
- **`set.py`**: Creating sets, adding elements, and exploring distinct set behaviors.
- **`university.py`**: Storing and accessing complex structures using dictionaries.
- **`function.py`**: Writing functions with arguments and return values (e.g., area calculations).
- **`heklwe.py`**: Simple terminal input and greeting output script.
- **`studentmanagement.py`**: Simulating student profile properties (name, age, CGPA, graduation status).
- **`Real-World E-commerce.py`**: Simulating an e-commerce inventory item with pricing, discount calculation, and stock counts.
- **`codes file/`**: Subfolder containing secondary scripts:
  - `calculator.py`: Standard numeric operations.
  - `class_object.py`: Implementing simple class templates.
  - `condition.py`, `loops.py`, `functions.py`: Consolidated logic files.
  - `dictionary_comprehension.py`, `list_comprehension.py`: Advanced iteration syntax.
  - `exception.py`: Custom error handling demonstrations.
  - `file_handling.py`, `main.py`, `variables.py`: Code organization exercises.

## Key Learning Outcomes
- Mastering Python control flow and core data structures.
- Utilizing built-in functions and dictionary manipulation.
- Structuring modular projects and implementing classes and error handling.
