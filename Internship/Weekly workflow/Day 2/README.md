# Day 2: Dashboard Prototype Development & UI/UX Styling

## Activities & Processes
1. **UI Layout and Sidebar Implementation**: Created the sidebar radio selection buttons for navigation across all planned dashboard views.
2. **Presentation Styling with CSS**: Injected custom CSS stylesheets to establish a dark-mode theme, styled metric boxes, and adjusted spacing/margins to ensure the dashboard remains legible during presentations.
3. **Component Coding**: Set up structure placeholders and basic tables for segment profiles, individual customer search, and interactive data visualization.
4. **Initial Prototype Auditing**: Checked dataset loading mechanics within the Streamlit runtime, validating basic table outputs.
